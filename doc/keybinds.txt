*Explorateur📂*

-----------------------------------------------------------------------------------------
	Il fonctionne comme un buffer normal:
		- rajouter une ligne rajouteras un fichier/dossier.
		- supprimer une ligne supprimeras le fichier/dossier.
		- On peut yank un fichier, ca copieras aussi son contenu.
		- On peut creer un dossier et fichier en une seule fois : /dossier/dossier2/file.
	Keybinds :
		- in normal :
			- `<leader>e` : toggle the file explorer.
		- in file explorer:
			- `<C-l>` : go into folder/open file.
			- `<C-h>` : go into parent folder.
			- `<C-c>` : close file explorer.


*Arbre*

-----------------------------------------------------------------------------------------
	Un explorateur de fichier en arborescence
	Keybinds :
		- in normal :
			- `<leader>en` : toggle the file explorer.
		- in file explorer:
			- `<CR>` : Open a file
			- `<space>` : Toggle a folder being open/closed
			- `a` : Add a folder of file
			- `r` : Rename a file
			- `d` : Delete a file

*Paneaux🖥️*

-----------------------------------------------------------------------------------------
	Pour naviguer enter paneaux, il faut utiliser `Ctrl`.
	Keybinds :
		- `<C-l>` : alle dans le paneau de de droite.
		- `<C-k>` : alle dans le paneau du haut.
		- `<C-j>` : alle dans le paneau du bas.
		- `<C-h>` : alle dans le paneau de gauche.


*Redimensionner↔️*

-----------------------------------------------------------------------------------------
	Il faut utiliser `Alt`.
	Keybinds :
		- `<A-+>` : Augmenter la taille verticale.
		- `<A-->` : Diminuer la taille verticale.
		- `<A-,>` : Augmenter la taille horizontale.
		- `<A-.>` : Diminuer la taille horizontale.


*Browser🌐*

-----------------------------------------------------------------------------------------
	Il faut utiliser `<leader>b` + something, avec b pour browser
	Keybinds:
		- `<leader>bb` : ouvre les bookmarks
		- `<leader>bi` : ouvre une recherche avec un texte, i pour insert


*Telescope🔭*

-------------------------------------------------------------------------------
	Il faut utiliser `<leader>f` + something, avec f pour find
	Keybinds:
		- `<leader>ff` : chercher dans les fichiers, f pour file.
		- `<leader>fg` : chercher une string dans les fichier, g pour grep.
		- `<leader>fm` : chercher une page du manuelle, m pour man
		- `<leader>fh` : chercher une page de :help, h pour help
		- `<leader>fb` : chercher dans un buffer, b pour buffer
		- `<leader>fn` : chercher dans les notifications, n pour notification
		- `<leader>fr` : chercher dans les registres, r pour registre
		- `<leader>fo` : chercher dans les fichier recents, o pour old pages
		- `<leader>rff` : comme <leader>ff mais relatif au fichier actuel, r pour relative
		- `<leader>rff` : comme <leader>fg mais relatif au fichier actuel, r pour relative

*Tabs🗂️*

-----------------------------------------------------------------------------------------
	Il faut utiliser `<leader>t` something (t pour tab), pour creer un supprimer une tab.
	Il faut utiliser `<C-H>` ou `<C->>` pour se deplacer entre les tabs.
	Keybinds:
		- `<leader>tn` : creer un nouveau terminal, n pour new
		- `<leader>tc` : fermer le terminal, c pour close
		- `<C-A-l>` : aller dans la tab de gauche.
		- `<C-A-h>` : aller dans la tab de droite.

*Lsp󱃖*

-----------------------------------------------------------------------------------------
	Il faut utiliser <leader>l + something, l pour lsp.
	Keybinds :
		`<leader>ldf`: aller a la |definition|
		`<leader>ltdf`: aller a la |type| |definition|
		`<leader>lw`: liste les |symboles| du |workspace|
		`<leader>lic`: liste les fonctions qui appellent cette fonction, ic
		pour |incoming| |calls|
		`<leader>loc`: liste les fonctions que cette fonction appelle, oc pour
		|outgoing| |calls|
		`<leader>ldc`: aller a la |declaration|
		`<leader>lrf`: aller aux |references|, rf pour references.
		`<leader>lim`: aller a l' |implementation
		`<leader>lh`: aller au |hover|, h pour hover.
		`<leader>lc`: aller aux |code_actions|, c pour code actions.
		`<leader>lrn`: rename, rn pour rename.
		`<leader>lp`: toggle l'affichage des parametres (inlay_hint)
		`<leader>le`: ouvrir un popup pour le warning/erreur/diagnostic de
		lsp, e pour erreur.
	Expliquations :
		*declaration*: C'est l'introduction d'un symbole :
			- int test;
			- void foo();
			- class Bar;
		*definition*: C'est le code dans lequel le symbole prend une valeur :
			- test = 4;
			- foo = {}
			- class Bar {}
		*implementation*: S'applique aux interfaces et classes/functions
		abstraites, il represente l'endroit dans lequel ces symboles sont
		soit override pour une methode ou heriter pour une classe :
			- void method ovveride {}
			- class Child : public Base
		*references*: C'est l'endroit dans lequel ce symbole est utilise:
			- test + 5
			- foo()
		*hover*: ce sont des informations sur le symbole, ou il est definit, ce
		qu'il represente ...
		*code_actions*: Ce sont des quick fix faisable par le lsp.
		*inlay_hint*: Ce sont les noms des parametres des fonctions, ils
		peuvent etre affiche juste a gauche de leur valeur.
